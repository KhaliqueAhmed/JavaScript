# Web Tutorials Workspace

This repository contains practice files and mini projects for learning JavaScript, HTML, and CSS.

## Project Structure

- `app.js`, `codes.js`, `script.js`, `style.css` — root-level practice files
- `promises.html` — Promise-related practice page
- `JS/` — JavaScript concept demos and exercises
  - Topics include: callbacks, async/await, events, DOM listeners, API/fetch, transitions, toggles, counters, tables, and portfolio page practice
  - `task2/` and `task3/` include task-based exercises
- `js mini project/` — small standalone web project (`index.html`, `style.css`, `app.js`)
- `Tic_Toe/` — Tic-Tac-Toe mini project (`index.html`, `style.css`, `app.js`)

## How to Run

Since this is a static HTML/CSS/JS workspace, you can run files directly in your browser:

1. Open any `.html` file in a browser, or
2. Use VS Code Live Server for a smoother development workflow.

## Learning Focus

- JavaScript fundamentals
- DOM manipulation
- Event handling
- Async programming (`callbacks`, `Promises`, `async/await`)
- API consumption with `fetch`
- Small project-based practice
